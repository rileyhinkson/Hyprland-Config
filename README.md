# dotfiles

Hyprland setup shared between laptop and desktop.

New machine:

    git clone git@github.com:rileyhinkson/dotfiles.git ~/dotfiles
    ~/dotfiles/install.sh

Sync: `git pull` to get changes, `git add -A && git commit -m "..." && git push` to share them.
Monitor layouts (`config/hypr/monitors.*`) stay per machine and are not tracked.
